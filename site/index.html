What the numbers mean. CPU is Chromium renderer main-thread task time during an 800 ms observation window; animations last 600 ms. Numbers are medians; ratios use paired medians with a 95% bootstrap interval. Equivalence requires the entire interval inside 0.95–1.05. 3 of 3 WAAPI workloads meet that criterion. The table separates JavaScript cost from style and layout work performed by the browser. Frame cadence is about 16.7 ms; equal FPS alone does not prove equal CPU cost.
Correctness first. Every element is checked at five paused timeline positions and at completion. A separate natural-playback check inspects every animated property on every element across three fresh pages per side; it verifies continuous progress against the elapsed or native WAAPI timeline. The full animate() string-transform case fails the sampled-timeline check and is excluded from timing. Six passing workloads are a bounded comparison, not full API parity.
